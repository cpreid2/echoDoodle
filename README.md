## echoDoodle is a tiny drawing app that thinks it's a sequencer.
https://cpreid2.github.io/echoDoodle/

echoDoodle is built on a simple idea: **that making something move should feel
like play, not work.** You don't need to be an animator. You don't need expensive software.
You just need a moment, a mouse, and the willingness to make one small mark.

Your doodle keeps going long after you've let go
